# Project Title

Information Architecture Map for Amazon Application

---

# Introduction

Information Architecture (IA) is the process of organizing and structuring information in a way that helps users easily navigate an application or website. This project focuses on designing an Information Architecture Map for the Amazon application.

---

# Objectives

- Understand Information Architecture concepts.
- Organize application content into a logical hierarchy.
- Improve navigation and user experience.
- Create a professional Information Architecture diagram.

---

# Tools Used

- Draw.io (diagrams.net)
- GitHub

---

# Methodology

1. Selected Amazon as the sample application.
2. Identified the primary navigation sections.
3. Created parent-child relationships between pages.
4. Designed the Information Architecture diagram.
5. Exported the final diagram as PNG.
6. Uploaded the project files to GitHub.
